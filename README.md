# A3-ConfigDB

A3-ConfigDB is an open-source, local-first configuration exploration platform for Arma 3 datasets generated by users from content they are legitimately entitled to access.

The public repository contains software, documentation, schemas and artificial `A3CDB_Test_*` fixtures only. It does not distribute Arma 3, DLC, cDLC or mod configuration databases.

## Current public preview

At the PUB028 architecture checkpoint, the validated artificial-data stack includes:

- A3DM complete snapshot schema and validation;
- immutable snapshot loading with inherited-property resolution;
- A3IX exact and nested-property indexes;
- A3QM normalized query model;
- A3QL v0.1 parser and runtime;
- A3QE deterministic query execution;
- Browser backend with stable JSON responses;
- mobile-first Basic and Advanced search interfaces;
- Basic and C++-style Advanced class sheets;
- public Python, compilation and Docker CI.

The project is not yet the complete local product. User-selected dataset loading, text indexing, relation navigation, exports and the A3XE extractor remain planned work.

## Snapshot-first doctrine

One extraction represents one complete final configuration snapshot observed by Arma 3 for a specific launch preset. The game has already resolved configuration priority before export. Addon order is recorded as provenance metadata.

Differential storage is not part of the A3DM core. Future dataset comparison belongs to A3DIFF.

## Planned usage modes

- **Public Demo** — artificial fixtures only.
- **Local Database** — users generate, validate, index and browse their own data locally.
- **Self-hosted Server** — users may host the software with their own locally generated dataset, subject to applicable rights and the project license.

A3-ConfigDB is not a hosted game-data service. Real configuration data remains under the control of the user who generated it.

## Data policy

No real Arma 3 configuration database is included in this repository. Public fixtures use only synthetic `A3CDB_Test_*` class names and values. See [`DATA_POLICY.md`](DATA_POLICY.md).
